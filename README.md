# Projeto_web_II
O “FoxKey” é um sistema web projetado para otimizar processos da
distribuidora cliente, fazendo desde a gestão de estoque até o controle de vendas.
Esse software foi feito para atender às necessidades específicas da distribuidora,
reduzindo custos, automatizando seus processos e aprimorando a experiência do
cliente.

O Projeto está incompleto com funcionalidades parciais. para Executá-lo corretamente, siga as instruções.

1. FrontEnd (Vue)
Acesse a pasta webFoxKey -> no console npm install -> npm run dev.

2. API (Asp net)
Baixe em: https://github.com/LucayanFelipe/ApiFoxKey
A API está em C# asp net, recomendado que rode com visual studio 2022.

3. Banco de dados (mysql)
No mesmo github da API está o arquivo .sql execute com mysql workbench.
